A self-hosted mini-SOC for practising real detection and investigation workflows.

- Deployed **Wazuh Manager & Dashboard** on **Ubuntu Server**
- Connected a **Windows 11** endpoint using the **Wazuh Agent** and **Sysmon**
- Monitored Windows process-creation events (**Event ID 1**)
- Wrote **custom detection rules** for discovery commands: `whoami.exe`, `ipconfig.exe`, `systeminfo.exe`
